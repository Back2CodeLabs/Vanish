👻 Vanish

Effet "disparition Thanos" (Avengers: Infinity War) sur n'importe quel élément du DOM — clique une carte pour la voir se désintégrer, ou utilise les boutons ci-dessous.

Clique-moi

Chaque carte se désintègre indépendamment quand tu cliques dessus — texte, badge et fond compris.

Vanilla JS

Aucune dépendance framework

Une seule dépendance réelle : html2canvas, pour capturer l'élément avant de le pulvériser en fragments.

Zéro build

Réutilisable partout

Fonctionne sur n'importe quel élément HTML — une carte, un paragraphe, une image, une section entière.

DOM-agnostique

Balayage gauche → droite

Les fragments de gauche s'envolent en premier, ceux de droite en dernier — comme la poussière originale du film.
